## 1. 문(BP_Door) 복기

### 1-1. 컴포넌트 역할

```
BP_Door
 └ DefaultSceneRoot
    ├ Hinge   (Scene)          ← 회전축
    │  └ Door (Static Mesh)    ← 실제 문
    └ Trigger (Box Collision)  ← 감지 영역
```

| 컴포넌트 | 역할 |
|---|---|
| **DefaultSceneRoot** | 액터의 최상위 컴포넌트. 액터의 위치 기준. 루트가 비어 있으면 자동 생성 |
| **Hinge** | Door의 부모로 쓰이는 **회전축(회전 기준점)**. 모양·충돌 없는 씬 컴포넌트 |
| **Door** | 실제로 보이는 물체. **Block** 충돌로 플레이어를 막음 |
| **Trigger** | 플레이어 접근을 **감지**하는 Overlap 영역. Hinge의 자식이 아니라서 회전하지 않음 |

### 1-2. 노드 역할

| 노드 | 역할 |
|---|---|
| **Set Relative Rotation** | 대상 컴포넌트의 회전을 **부모 기준으로 지정한 값으로 설정**. 더하지 않고 덮어씀 (더하기는 `Add Relative Rotation`) |
| **Timeline** | 정해진 시간 동안 **변하는 값(트랙)** 을 만들어 내는 노드 |
| **Lerp** | A와 B 사이에서 Alpha(0 ~ 1) 비율에 해당하는 값을 돌려줌. **시간 개념 없음** |

### 1-3. 타임라인 핵심

| 요소 | 의미 |
|---|---|
| **Play** | 현재 위치에서 정방향 재생 시작. 재생 중 **매 프레임 Update 실행** |
| **Reverse** | 현재 위치에서 **역방향 재생**. 동작을 직접 되돌리는 게 아니라 **시간을 거꾸로** 재생 |
| **Track** | 키의 시간 = 실행 시간, 키의 값 = 변화 정도, 커브 = 변화하는 느낌 |
| **Alpha 핀** | 기본으로 없음. **Float 트랙을 만들고 이름을 지으면** 그 이름으로 생김 (트랙 이름 = 핀 이름) |

**문이 닫히는 원리:**

```
End Overlap → Reverse → Alpha가 1 → 0 → Lerp 결과 90° → 0° → 문이 닫힘
```

- 문을 닫는 것은 **Reverse**, 그 변화를 문에 전달하는 통로가 **Alpha**입니다.
- **Alpha가 연결되어 있지 않으면** (Open Angle을 바로 Z에 연결하면) 항상 같은 각도가 들어가서, 순간적으로 열리고 Reverse를 해도 닫히지 않습니다.

### 1-4. 타임라인과 Lerp의 역할 분담

```
[타임라인]  시간 담당   "0.5초 동안 0 → 1로 변하는 값을 내보냄"
[Lerp]     범위 담당   "받은 비율을 0° ~ 90° 사이 값으로 바꿈"
```

- Lerp 혼자서는 시간에 따라 변하지 않습니다. 타임라인이 Alpha를 계속 바꿔 넣어 주기 때문에 결과가 변합니다.

### 1-5. 플레이어만 감지하도록 수정 (Cast 적용)

```
[Begin Overlap] ─▶ [Cast To BP_ThirdPersonCharacter] ─성공─▶ 타임라인 Play
     Other Actor ───▶ Object

[End Overlap]   ─▶ [Cast To BP_ThirdPersonCharacter] ─성공─▶ 타임라인 Reverse
     Other Actor ───▶ Object
```

- **Cast Failed는 연결하지 않음** → 플레이어가 아니면 아무 일도 일어나지 않음
- Cast 노드는 **이벤트마다 하나씩** 둡니다.

## 2. 보편적으로 사용하는 충돌

### 기본 원칙

| 물체의 성격 | 설정 | 예시 |
|---|---|---|
| 통과하면 안 되는 물체 | **Block** | 벽, 바닥, 문, 바위 |
| 통과는 되지만 이벤트가 필요한 물체 | **Overlap** | 트리거, 아이템, 체크포인트 |
| 통과해도 되는 장식 | **NoCollision** 프리셋 | 풀, 작은 돌, 이펙트 |

- "장식인가"가 아니라 **"통과해도 되는가"** 로 나눕니다.

### 플레이어 캡슐 기본값 (`Pawn` 프리셋)

| 상대 | 반응 |
|---|---|
| WorldStatic, WorldDynamic, Pawn, PhysicsBody 등 물체 | Block |
| **Visibility, Camera** (보이지 않는 선) | **Ignore** |

### Ignore와 NoCollision

| 구분 | 의미 |
|---|---|
| Ignore | 충돌은 켜져 있고 **특정 상대에게만** 반응하지 않음 |
| NoCollision | 충돌 기능 자체를 끔 → 가벼움 |

### 반응은 상대마다 다르게

| 물체 | 플레이어 | 총알 | 카메라 |
|---|---|---|---|
| 일반 벽 | Block | Block | Block |
| 투명 벽 (맵 경계) | Block | Ignore | Ignore |
| 작은 소품 | Block | Block | Ignore |
| 아이템·트리거 | Overlap | Ignore | Ignore |

- 설정: 콜리전 프리셋 → **`Custom...`** → 채널별 표

### 콜리전 활성화 방식

| 방식 | 의미 | 예시 |
|---|---|---|
| No Collision | 충돌 없음 | 장식 |
| Query Only | 감지만 | 트리거 |
| Physics Only | 물리만 | 잔해 |
| Query and Physics | 감지 + 물리 | 벽, 문, 캐릭터 |

## 3. 형변환 (Cast)

### 용도

**"이 대상이 정말 특정 클래스인지 확인하고, 맞으면 그 클래스로 다룰 수 있게 해 주는 노드"** 입니다.

Overlap 이벤트의 `Other Actor`는 타입이 그냥 **Actor**라서 누가 들어왔는지 구분할 수 없습니다. Cast로 확인해야 합니다.

```
들어온 것 (Actor 타입)
      ▼
[Cast To BP_ThirdPersonCharacter]   "플레이어 캐릭터 맞아?"
      ├─ 맞음 → 성공 실행선 + 플레이어 참조 제공
      └─ 아님 → Cast Failed 실행선
```

**비유:** 입구의 신분증 확인. 직원증이 확인된 사람만 통과시킵니다.

### Cast 노드의 핀

| 핀 | 종류 | 의미 |
|---|---|---|
| 실행 입력 (왼쪽 위) | 실행 | Cast 실행 |
| Object | 데이터 | 확인할 대상 |
| **성공** (오른쪽 위) | 실행 | 맞으면 **다음에 무엇을 실행할지** |
| **Cast Failed** | 실행 | 아니면 실행할 것 |
| **As BP Third Person Character** | 데이터 | **그 플레이어를 가리키는 참조**. 변수·함수에 접근할 때 사용 |

- **흰 선 = "언제, 무엇을 실행할지"**, **파란 선 = "누구에게 할지"**

### 클래스 계층과 Cast 범위

```
Actor
 └ Pawn
    └ Character
       └ BP_ThirdPersonCharacter
```

| Cast 대상 | 통과하는 것 |
|---|---|
| `Cast To BP_ThirdPersonCharacter` | 그 블루프린트(와 그 자식)만 |
| `Cast To Character` | 모든 캐릭터 (적 캐릭터 포함) |
| `Cast To Pawn` | 조종 가능한 모든 대상 (차량 등 포함) |

### 사용법

1. 이벤트의 **`Other Actor`** 핀을 끌어서 빈 곳에 놓기
2. **`Cast To <클래스>`** 검색 → 선택 (Object 자동 연결)
3. 이벤트 흰 선 → Cast 입력, Cast **성공** → 다음 노드

### 주의 사항

- 실행선이 Cast의 입력에 들어가지 않으면 Cast가 실행되지 않습니다.
- 캐릭터를 다른 블루프린트로 바꾸면 Cast 대상도 바꿔야 합니다.

## 5. 실습: 코인 줍기와 점수

### 완성 동작

- 코인이 제자리에서 회전
- 플레이어가 닿으면 점수 +1, 화면에 점수 출력, 코인 제거

### 점수 변수 (BP_ThirdPersonCharacter)

| 이름 | 타입 | 기본값 | 인스턴스 편집 가능 |
|---|---|---|---|
| `Score` | Integer | 0 | ❌ |

- 점수는 **플레이어가 가지고 다니는 값**이라 캐릭터에 둡니다.
- 소수점이 필요 없으므로 **Integer**를 씁니다.

### BP_Coin 컴포넌트

```
BP_Coin
 └ DefaultSceneRoot
    ├ Mesh     (Static Mesh: Cylinder) ← NoCollision
    └ PickArea (Sphere Collision)      ← OverlapAllDynamic
 RotatingMovement                      ← 트리 바깥 (액터 컴포넌트)
```

| 컴포넌트 | 설정 |
|---|---|
| Mesh | 위치 Z 50, 회전 X 90, 스케일 0.5 / 0.5 / 0.1, **NoCollision** |
| PickArea | 위치 Z 50, 구체 반경 60, **OverlapAllDynamic** |
| RotatingMovement | 회전 속도 Z 180 (초당 180도) |

### 문과 코인의 충돌 설계 비교

| | 문 | 코인 |
|---|---|---|
| 보이는 메시 | **BlockAll** (막음) | **NoCollision** (통과) |
| 감지 영역 | Box, OverlapAllDynamic | Sphere, OverlapAllDynamic |
| 움직임 | 타임라인으로 Hinge 회전 | RotatingMovement로 계속 회전 |

### 이벤트 그래프

**실행 순서 (흰 선)**

```
Begin Overlap (PickArea) → Cast 성공 → Set Score → Print String → Destroy Actor
```

**값의 흐름 (색 선)**

```
Cast 결과(플레이어 참조) → Get Score → + 1 → Set Score의 Score 입력 → (To String) → Print String
```

**연결 목록**

| 선 | 출발 | 도착 |
|---|---|---|
| 흰색 | Begin Overlap | Cast 입력 |
| 흰색 | Cast **성공** | SET 입력 |
| 흰색 | SET 출력 | Print String |
| 흰색 | Print String | Destroy Actor |
| 파랑 | Other Actor | Cast Object |
| 파랑 | Cast **As BP Third Person Character** | Get Score의 Target |
| 파랑 | Cast **As BP Third Person Character** | SET의 Target |
| 청록 | Get Score | + 노드 A (B = 1) |
| 청록 | + 노드 결과 | SET의 **Score** |
| 청록 | SET 출력 Score | Print String In String (변환 노드 자동 생성) |

### 사용 노드

| 노드 | 역할 |
|---|---|
| Get (변수) | 변수 값 **읽기** |
| Set (변수) | 변수 값 **저장**. 저장된 값을 오른쪽으로 다시 내보냄 |
| Add (+) | 두 값 더하기 |
| To String | 숫자를 글자로 변환 (자동 생성) |
| Print String | 화면 왼쪽 위에 글자 출력. **개발 전용** (출시 빌드에서는 빠짐) |
| Destroy Actor | 액터를 레벨에서 제거 |

### 주의 사항

- **Get / Set은 Cast 결과 핀에서 끌어서** 만듭니다. 빈 곳에서 만들면 Target이 비어 "누구의 Score인지" 몰라 오류가 납니다.
- **Destroy Actor는 맨 마지막**에 둡니다.

## 6. 변수 Get과 Set

### 역할

| 노드 | 역할 |
|---|---|
| **Get** | 현재 값을 **읽음** |
| **Set** | 입력된 값으로 **바꿈**. 실제로 데이터가 변하는 시점 |

### Set은 Get 없이도 쓸 수 있다

| 하고 싶은 것 | Get 필요 | 예시 |
|---|---|---|
| 고정값으로 바꾸기 | ❌ | 점수를 0으로 초기화 |
| 다른 값으로 바꾸기 | ❌ | 체력을 최대 체력으로 |
| **이전 값 기준으로 바꾸기** | ✅ | 점수 +1, 체력 −10 |

```
Set Score ← 0                   "점수를 0으로"
Set Health ← Get MaxHealth       "체력을 최대치로"
Set Score ← Get Score + 1        "점수를 1 올림"
```

- Set의 입력에 아무것도 연결하지 않으면 **칸에 적힌 값(기본 0, false)** 으로 저장됩니다. 의도치 않은 초기화의 흔한 원인입니다.
- 다른 액터의 변수라면 Get·Set 모두 **Target**에 그 액터를 연결해야 합니다.

## 7. 블루프린트 실행 규칙

### 실행 노드와 순수 노드

| 구분 | 실행선(흰 삼각형) | 언제 동작하나 | 예시 |
|---|---|---|---|
| **실행 노드 (Impure)** | 있음 | 흰 선을 따라 **차례가 왔을 때** | Set, Cast, Print String, Destroy Actor |
| **순수 노드 (Pure)** | 없음 | 다른 노드가 **값을 요청할 때** | Get, +, To String, Lerp |

### 순서가 보장되는 원리

**실행 노드는 실행되기 직전에 자기 입력값부터 계산합니다.**

```
1. 흰 선을 따라 SET 차례가 옴
2. SET: "Score 입력값이 필요해" → 연결된 쪽으로 거슬러 올라감
3.   + 노드: "A 값이 필요해" → Get Score 실행 → 3
4.   + 노드: 3 + 1 = 4
5. SET: 플레이어 Score를 4로 저장  ← 여기서 처음 값이 바뀜
```

- **Set의 입력에 "Get + 1"이 연결되어 있기 때문에** Set 실행 전에 그 계산이 반드시 먼저 일어납니다. **연결 관계가 순서를 정합니다.**
- 연결이 끊긴 순수 노드는 **아무도 값을 요청하지 않으므로 실행되지 않습니다.**

### 주의: 순수 노드는 요청될 때마다 다시 계산된다

| Print String 입력 연결 | 출력 값 | 이유 |
|---|---|---|
| SET의 출력 핀 | 4 | 방금 저장한 값 |
| Get Score에서 새로 연결 | 4 | 다시 읽음 (이미 4) |
| + 노드 출력에서 연결 | **5** | 다시 계산 (4 + 1) |

- 저장한 값을 쓰고 싶으면 **Set의 출력 핀**을 사용합니다.

### 한 줄 요약

> 흰 선은 **"무엇을 언제 실행할지"**, 색 선은 **"실행할 때 어떤 값을 가져올지"** 를 정한다.
> 실행 노드는 차례가 오면 색 선을 거슬러 올라가 필요한 값을 먼저 계산한다.

## 8. 자주 하는 실수

| 증상 | 원인 | 해결 |
|---|---|---|
| 타임라인에 Alpha 핀이 없음 | 트랙을 만들지 않음 | 타임라인 편집기에서 Float 트랙 추가 |
| 문이 순간적으로 열리고 안 닫힘 | Lerp 없이 Open Angle을 바로 Z에 연결 | 타임라인 Alpha → Lerp → Z |
| 코인이 안 사라지고 점수도 안 나옴 | Cast **성공** → SET 흰 선 누락 | 흰 선 연결 |
| 점수가 항상 0 | + 결과가 SET의 Score에 미연결 (칸에 0) | + 결과 → SET Score |
| Get / Set 컴파일 오류 | Target 비어 있음 | Cast 결과 핀에서 끌어서 생성 |
| RotatingMovement가 루트 아래 안 생김 | 위치 없는 액터 컴포넌트 | 정상 (트리 바깥 표시) |
| 코인에 몸이 막힘 | Mesh 콜리전이 NoCollision 아님 | Mesh → NoCollision |
| Print String 아래 줄무늬 | 개발 전용 노드 표시 | 정상 |

## 9. 앞으로 배울 블루프린트 범위

### 지금까지 배운 것

|---|---|

| 충돌 | Block / Overlap / Ignore, 채널, 프리셋 |
| 변수 | 타입, Get / Set, 인스턴스 편집 가능 |

| 시간 처리 | 타임라인, Lerp |
| 기타 | Destroy Actor, Print String, Rotating Movement |

### 필수

| 분야 | 개념 | 쓰이는 곳 |
|---|---|---|
| 흐름 제어 | Branch, Sequence, For Each Loop, Do Once, Delay | 조건 분기, 반복, 한 번만 실행 |
| 함수와 이벤트 | 함수, 커스텀 이벤트, 매크로, 지역 변수 | 반복 로직 묶기 |
| 블루프린트 통신 | 직접 참조, Cast, 인터페이스, 이벤트 디스패처 | 스위치로 멀리 있는 문 열기 |
| 입력 | Enhanced Input (입력 액션, 매핑 컨텍스트) | 키로 상호작용 |
| UI | UMG 위젯, 바인딩 | 점수·체력 표시, 메뉴 |
| 스폰과 타이머 | Spawn Actor from Class, Set Timer by Event | 총알 발사, 주기적 생성 |

데이터(배열, 맵, 구조체, 열거형, 데이터 테이블), GameState·PlayerState·GameInstance 활용, SaveGame, Open Level, 디버깅(브레이크포인트, Watch)

### 심화 (선택)

애니메이션 블루프린트, AI(Behavior Tree), 머티리얼, 나이아가라, 사운드
