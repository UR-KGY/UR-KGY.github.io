## 트러블 슈팅

### 1. `StrategySelectionException` — MySQL8Dialect를 찾을 수 없음

```
StrategySelectionException: Unable to resolve name [org.hibernate.dialect.MySQL8Dialect] as strategy [org.hibernate.dialect.Dialect]
Caused by: ClassNotFoundException: Could not load requested class: org.hibernate.dialect.MySQL8Dialect
```

- **원인**: `application.properties`의 아래 줄이 문제
  ```
  spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect
  ```
  초기 설정을 위해 AI에게 JPA + MYSQL 기본 설정을 만들어 달라 요청했더니 오래된 버전을 가져온 것이었다.
  Spring Boot 4.1.0 + Hibernate 7.4.1 조합에서는 `MySQL8Dialect` 클래스가 더 이상 존재하지 않는다. 
- **해결**: 해당 줄을 삭제. Hibernate 6 이상부터는 연결된 DB 메타데이터를 보고 dialect를 **자동 감지**하므로 명시할 필요가 없었다.


### 2. 빈(Bean)을 찾을 수 없음 — DI 실패

```
Parameter 0 of constructor in com.gamebasic.game.controller.GameController required a bean of type
'com.gamebasic.game.service.GameService' that could not be found.
```

- **원인**: `GameService` 클래스에 `@Service` 어노테이션이 없어서 스프링 컨테이너가 빈으로 등록하지 못함 (2번 과정).
- **해결**: `@Service` 어노테이션 추가.


### 3. `GET /games` 405 Method Not Allowed

- **원인**: `index.html` 접속 시 프론트에서 자동으로 `GET /games`를 호출하는데, 컨트롤러의 매핑은 `/game`(단수)으로 되어 있었다. (문제 )
- **해결**: 컨트롤러 매핑 경로를 실제 프론트가 호출하는 경로(`/games`)와 일치시켰다.


### 4. `POST /games` 500 Internal Server Error — 읽기 전용 트랜잭션

- **원인**: 게임 생성 서비스 메서드에 `@Transactional(readOnly = true)`가 붙어 있어 INSERT가 반영되지 않았다.
- **해결**: 쓰기 작업이 필요한 메서드는 `readOnly` 옵션을 빼거나 `@Transactional(readOnly = false)`(기본값)로 지정. 201 Created 응답과 DB 반영을 확인.


### 5. `UnexpectedTypeException` — Integer에 `@Size` 사용

```
jakarta.validation.UnexpectedTypeException: HV000030: No validator could be found for constraint
'jakarta.validation.constraints.Size' validating type 'java.lang.Integer'. Check configuration for 'deck[0].acquiredFloor'
```

- **원인**: `Integer` 타입 필드에 문자열/컬렉션 길이 제한용 어노테이션인 `@Size`를 사용했었다.
- **해결**: 숫자 범위 제한은 `@Min`, `@Max`(또는 `@Positive`, `@Range` 등)를 사용해야 하는 것을 다시 배웠다.

### 제네릭 와일드카드 `<?>`
`List<?>`처럼 타입 파라미터 자리에 `?`를 쓰면 "어떤 타입이든 허용"하는 언바운디드 와일드카드가 된다. 상한을 두고 싶으면 `<? extends T>`(T와 그 하위 타입만), 하한을 두고 싶으면 `<? super T>`(T와 그 상위 타입만)를 사용한다. 
과제에선 명세서대로 타입을 정확하게 기재해야 하였기에 요청DTO로 타입을 바꾸었다.
