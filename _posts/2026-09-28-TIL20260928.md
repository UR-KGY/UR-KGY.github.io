# 기획 및 역할 분담 완료
- 서버 개발자 역할을 맡음(필요 시 클라이언트도)
- 오늘 일정은 기획 외엔 강의를 들으면서 aws 활용법을 배웠음
- 강의를 듣고 막상 실습을 해보려니 잘 되지 않음. (IAM 쪽을 다시 봐야할 것 같다.)
- EC2엔 데이터를 되도록 두지 않고 S3, RDS 등을 사용하여 데이터 관리 
- EC2 에 앱을 올려놓고 parameter store에서 환경변수를 할당해야하는데 오류는 내일 찾아봐야할 것 같다.
- 내일 정전 예정 노트북과 usb(pem 키 및 secret key 담아가기) 를 들고 외출
- AWS 정리는 강의를 전부 끝까지 수강하고나서 종합적으로 정리 예정


## 트러블 슈팅 EC2 와 연결된 터미널에서 경로를 찾으려 하였음
- 처음엔 경로가 잘못되어서 그런줄 알았는데
- 터미널이 EC2와 연결되어 있어서 강의처럼 EC2 에 빌드된 앱을 올려놓지 못했었다.
