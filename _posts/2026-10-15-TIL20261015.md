# 현재 상황
- 클라이언트 팀은 게임의 외적 부분의 폴리싱 작업을 진행 중인 듯하다.
- 지출 내역을 살펴봤을 때 SUNO 의 청구서 (ai 음악제작?) , 아마도 Pixellab 의 청구서 (픽셀 그래픽 에셋 ai) 등을 찾아 볼 수 있었다.
- SUNO 가 45000원 PIXELLAB 이 32600원의 비용을 사용하였다고 하는데, 나중에 픽셀이나 사운드가 필요한 상황이 왔을 때 한번 사용해보면 어떨까 생각이 든다.
- 현재 내 진행 상황은 사실상 동결 상태라, 초기 기획안에서 상품의 판매기한이나 수량 제한등을 거는 등의 이후 추가될 수 있겠다 싶은 기능들을 따로 브랜치를 파서 만들어보고 있었다. 아마 지금 상태에서 기능을 추가하기엔 시간이 촉박하기에 추가되진 않을 것 같다.
- 현재 AWS 의 크레딧  사용량은 9월부터 합치면 30달러 정도를 소모한 듯 하다. 아마 크레딧 자체는 기한내까지 사용하는데 지장은 없을 것.
-  폴리싱을 진행하면서 데이터를 넣어보고(데이터 시트를 이야기 하는 것 같다.), 상점에도 띄워보는데(이것은 클라이언트의 화면 상 잘 나오는지를 말하는 걸까) 이 부분의 구매시 아티팩트 처리가 잘동작하는지 (playerArtifact 테이블에 데이터가 잘 들어가는 것은 확인하였다.) 확인 하는 것이었는데. 아티팩트 자체는 플레이어를 담당하시는 분이 구현하신 사항이고 잘 돌아가는 것 같아 이 부분에서 더 건들만한게 있을지 잘 모르겠다. 
- AWS 에 대해 더 이상 깊게 파고드는 것은 개발보다 또다른 API 사용법을 배우는 느낌이라, 지양하는 게 좋지 않을까 싶다. (필요할 때 쓰는 도구니까)
- 나중에 AWS 서버를 통해 배포를 진행한다면 다른 분들께 HTTP 와 WS 가 아닌 HTTPS 와 WSS 를 이용해달라 말해야한다.
- 내일은 비어있는 시간을 틈타 클라이언트 쪽이 어떻게 구현하였는지를 깃 허브의 커밋 내역을 보면서 학습할까 생각중이다.
